# revOS-V1
WebOS based on the french revolution

This is my first WebOS I made with the help of youtube almighty. I think its done pretty well but I am biased towards my own project of course so I cannot say. 
Anyway as mentioned in the first line this webOS is based on the french revolution. So to accurately depict that when closing the apps and folders a gulliotine (French people's favourite weapon) drops down and kills the apps (the graphics at least I tried to replicate it not the best but workable), 

Any way the project is made completely on HTML, CSS and JavaScript so its not the best but its better than nothing.

The project features a to do app, a working file manager and system monitor (somewhat), and the history as well I guess. It also has a light mode - dark mode toggle built in as well. It also features a functioning clock near the bottom in the taskbar. The taskbar also works like normal as in every other OS. Also it also suports multi file (app) opening and the window is dragabble. The apps also have minimizing, fullscreen functions as well. idk what more to write.
